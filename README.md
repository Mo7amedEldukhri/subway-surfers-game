# 🚇 Subway Surfers Game

لعبة Subway Surfers مبنية باستخدام **Flutter** و **Flame Engine**.

## 🎮 ميزات اللعبة

- ✅ شخصية رئيسية قابلة للتحكم (السحب لليمين واليسار)
- ✅ عوائق عشوائية متحركة
- ✅ عملات قابلة للالتقاط
- ✅ نظام النقاط والمكافآت
- ✅ زيادة صعوبة تدريجية
- ✅ شاشة نهاية اللعبة

## 📁 هيكل المشروع

```
lib/
```

## 🚀 البدء السريع

### المتطلبات
- Flutter SDK (v3.0.0+)
- Dart SDK

### التثبيت والتشغيل

```bash
# استنساخ المستودع
git clone https://github.com/Mo7amedEldukhri/subway-surfers-game.git
cd subway-surfers-game

# تثبيت المكتبات
flutter pub get

# تشغيل اللعبة
flutter run
```

## 🎮 آلية اللعب

### التحكم
- **السحب لليمين**: تحريك الشخصية يميناً
- **السحب لليسار**: تحريك الشخصية يساراً

### الأهداف
- تجنب العوائق الحمراء ❌
- التقط العملات الذهبية 💰
- اجمع أكبر عدد نقاط 🏆

### نظام النقاط
- كل ثانية: +10 نقاط
- كل عملة: +50 نقطة
- كل 1000 نقطة: تزداد السرعة والصعوبة

## 📚 شرح الكود

### SubwaySurfersGame - المحرك الرئيسي
- **onLoad()**: تحضير اللعبة
- **update()**: تحديث الحالة كل إطار
- **spawnObstacle()**: إنشاء عائق عشوائي
- **spawnCoin()**: إنشاء عملة عشوائية

### Player - الشخصية
- حركة سلسة باتجاه الهدف
- تقيد الحركة بحدود الشاشة

### Obstacle - العوائق
- كشف التصادم مع اللاعب
- رسم عائق أحمر

### Coin - العملات
- دوران تلقائي
- كشف تصادم دائري
